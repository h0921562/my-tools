プロジェクト

タップでそのプロジェクトの名刺を表示します。名刺のプロジェクトは、名刺の「編集」か、下の「まとめて移動」で変えられます。「親/子」のように「/」で区切ると、プロジェクトの中を細かく分けられます。

いま表示中の名刺（0件）をまとめて移動:

まとめて登録（複数枚）

名刺の写真を何枚でもまとめて選べます。1枚ずつ名刺として登録し、文字を自動で読み取ります（クラウド接続時はOpusで精読）。プロジェクト・会った日・場所は全部の名刺に入ります。

重複の可能性がある名刺

同じメール・電話番号、または同じ氏名＋会社の名刺をまとめています。残す名刺を選んで「統合」すると、空いている項目・タグ・メモを残す方へ集めて、他は削除します。

タグを整理

名前を変えると、そのタグが付いた名刺すべてに反映されます。既にあるタグ名に変えると1つにまとまります。

クラウド保存の設定

Google Apps Script の ウェブアプリ URL を入力すると、名刺データはスプレッドシートに、 画像は Google Drive に保存されます（あなた自身の Google アカウント内）。
URL は実質パスワードです。他人に共有しないでください。設定はこのブラウザにのみ保存されます。 未設定なら、これまで通りこのブラウザ内（IndexedDB）だけで動作します。
