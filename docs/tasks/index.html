タスクを追加

「GitHubで実行」でこの内容がIssueとして担当AIに渡ります（GitHub設定が必要）。「コピーして開く」で手動実行も可。
どのアカウントのトークンでIssueを作り、指示を送るか。「自動」はリポジトリの持ち主から判定します。
実行を始めたらセッションやPRのURLを貼っておくと、あとから一発で戻れます。

GitHubアカウント

個人用・仕事用など複数のGitHubアカウントを登録できます。タスクごとに使うアカウントが選ばれ、そのトークンで実行・確認します。トークンはこの端末のブラウザ内だけに保存され、書き出しJSONにも含まれません。
必要な権限を入力済みの作成画面を開く ↗
そのアカウントでログインした状態で開き、「Repository access」で対象リポジトリを選んで「Generate token」→ 表示された値をここに貼る。
Organizationのリポジトリを自動でこのアカウントに振り分けたいときに。

Codex の実行先

「Codex本体」は chatgpt.com/codex でGitHub連携を有効にしたリポジトリで使えます。ChatGPTのプランで動き、作業は chatgpt.com/codex にも表示されます。このとき codex.yml は反応しないので、二重に動くことはありません。

リポジトリのセットアップ

リポジトリを選んで「状況を確認」。足りないものはこの画面から登録・設定できます（キーは暗号化してGitHubのシークレットに保存され、この端末には残りません）。
