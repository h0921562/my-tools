AIタスク

Claude と Codex に頼むタスクを一か所で管理。GitHub経由でここから指示を出し、進み具合と結果を確認できます。

データについて
タスクはこの端末のブラウザ内に保存されます。別の端末へ移すときは書き出し→読み込みを使ってください。

タスクを追加

「GitHubで実行」でこの内容がIssueとして担当AIに渡ります（GitHub設定が必要）。「コピーして開く」で手動実行も可。
実行を始めたらセッションやPRのURLを貼っておくと、あとから一発で戻れます。

GitHub設定

この端末のブラウザ内だけに保存され、書き出しJSONにも含まれません。トークンを作成 ↗

リポジトリの準備（最初に1回）

  1. トークンの権限: 対象リポジトリを選び、Issues・Pull requests・Contents・Workflows を Read and write、Actions を Read に。
  2. 下のボタンで、対象リポジトリに Claude / Codex 用のワークフローを入れる。
  3. リポジトリの Settings → Secrets and variables → Actions にシークレットを登録:
    Claude: CLAUDE_CODE_OAUTH_TOKEN（PCで claude setup-token）または ANTHROPIC_API_KEY
    Codex: OPENAI_API_KEY
  4. （任意）Settings → Actions → General →「Allow GitHub Actions to create and approve pull requests」をONにするとCodexがPRまで自動作成。
